# **App Name**: Marisquería Online

## Core Features:

- Menú Digital con Código QR: Los clientes escanean un código QR en la mesa para ver el menú con fotos, precios y descripciones. El botón de emergencia está inmediatamente visible tras escanear el código.
- Alerta de Llamada al Mesero: Los clientes pueden presionar un botón de emergencia para enviar una alerta inmediata al mesero con el número de mesa.
- Gestión de Inventario con Alertas de Voz: El sistema emite alertas de voz cuando el inventario de un plato está bajo. El administrador y el mesero gestionan el stock.
- Inicio de Sesión de Mesero y Administrador: Meseros (Jhon:123456) y administradores (Maria:123456) inician sesión con cuentas separadas. Los meseros y administradores pueden editar platos y sus precios, pero solo el administrador tiene acceso a reportes y estadísticas.
- Gestión de Pedidos para Meseros: Los meseros ven el estado de cada mesa, registran pedidos en tablets, envían pedidos a la cocina, y reciben notificaciones de voz cuando un plato está listo para entregarse. Los pedidos marcados como "entregado" detienen las alertas de voz.
- Panel de Cocina: La cocina visualiza los pedidos con su estado (pendiente, preparando, listo) y los marca como finalizados.
- Análisis de datos con IA: Analiza patrones en las estadísticas de ventas para detectar automáticamente platos de alta rentabilidad que podrían beneficiarse de precios ligeramente aumentados; then recommends these opportunities via a tool

## Style Guidelines:

- Primary color: Sandy Yellow (#F4A460), evoking the beach and sunlight.
- Background color: Light beige (#F5F5DC) for a calm and neutral feel.
- Accent color: Soft Orange (#FFB347) to highlight key interactive elements.
- Body and headline font: 'PT Sans', sans-serif, offers a modern yet welcoming feel.
- Use simple, clean icons representing menu items and actions.
- The layout will use clear and spacious design to ensure a user-friendly experience.
- Subtle transitions and animations to provide a fluid and responsive feel when interacting with the app.
